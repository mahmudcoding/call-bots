# Call Bots 0.7.1

Google Meet bots now start correctly on a newly installed Mac.

- Call Bots explicitly opens the macOS Automation permission prompt the first
  time it controls its private Chrome copy. Choose **Allow** when it appears.
- If access was denied, the notification now points to **System Settings →
  Privacy & Security → Automation → Call Bots**.
- If Meet refuses a guest for another reason, the app keeps that exact reason
  in the notification instead of replacing it with “no bot reached the call.”

Meetings created by a personal Google account still do not accept anonymous
guests; use a Google Workspace meeting whose admin allows guest admission.
